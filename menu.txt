# THIS WEEK'S MENU
# ---------------------------------------------------------
# This one file runs BOTH your menu page (menu.html) and your
# order form (order.html). Change it here and both update.
#
# How it works:
#   - Lines that start with # are notes for you. The website ignores them.
#   - "== Name | price" starts a new section, like Breakfasts.
#     The price is what every dish in that section costs.
#   - Every other line is one dish, with parts split by a | line:
#       Name | Description | Tags | Ingredients | Price (optional)
#   - Tags can be GF (made without gluten), V (vegetarian), and NF (nut-free).
#     Separate them with commas, or leave that part empty.
#   - Only give a dish its own price if it's different from its section.
#     Write the number first, like "18 per quart".
#     For two sizes, separate them with a comma: "16 for six, 25 for a dozen".
#     A price that doesn't start with a number (like "Half the adult price")
#     shows on the menu, but it can't be ordered on the form.
#
# Each week: change the date, then type over the dishes.
# PRICE: meal prices are on the "==" lines. Add-on prices are at the end of each add-on line.
# =========================================================
